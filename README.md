# 屏幕推送
# 相当于盗版中育课堂助手

把电脑当前屏幕推到云笔记里，平板上打开就能看。

双击 `屏幕推送.exe` → 右下角出现小悬浮窗 → 点一下，平板上那本笔记里的图就换成当前的屏幕。

---

## 怎么用

1. 双击 `屏幕推送.exe`
2. 第一次会让你填**三项**：
   - **学校代码** —— 默认 `sxzxx`，决定连哪台服务器（`sxzxx` → `sxzxx-api.zyai.cc`）
   - **用户名**
   - **密码** —— 只存在你这台电脑上，不会写进 exe
3. 右下角出现悬浮窗，**点一下** → 推一张图
4. 按住悬浮窗可以**拖动挪位置**
5. **右键悬浮窗** → 切换模式 / 频率设置 / 日志开关 / 退出

右键菜单：

```
推送模式
 ✓ 手动（点击推送）
   智能（换应用才推）
   自动（每5秒推送）
──────────────────
 自动：推送间隔 6 秒…
 智能：最高刷新率 5 秒…
──────────────────
 ✓ 记录上传日志
 打开日志文件
──────────────────
 退出
```

### 上传日志

勾上「记录上传日志」，每次推送的过程都会记下来：

```
=== 屏幕推送 2026-10-04 21:08:53 手动触发 ===
截图：工作区 2456x1440 -> 图 1920x1126，218757 字节
登录中…
覆盖已有笔记：h5dm7ftiqm3l7psx7p7pfcxsn1kgcyg35
1/5 换 STS 凭证 …
2/5 上传模板文件 …
3/5 上传页面图 …
4/5 写资源清单 …
5/5 建笔记 …
完成：覆盖 h5dm7ftiqm3l7psx7p7pfcxsn1kgcyg35
```

- 源码模式（双击 `run_dev.bat`）→ 日志直接刷在黑窗口里
- exe 模式 → **没有黑窗口**，日志写在 `%LOCALAPPDATA%\ScreenPush\push.log`
- 每次推送**覆盖写**，文件永远是最近一次的过程，不会越长越大
- 出问题时先看这个文件——比"没反应"三个字有用得多

### 三种模式

右键悬浮窗切换，选中项会打钩。模式会记住，下次打开保持上次那个。

| 模式 | 行为 | 什么时候用 |
|---|---|---|
| **手动** | 点一下推一次 | 想推才推，流量完全自己说了算 |
| **智能** | 只在**换了应用**时推，最快不超过设定的"最高刷新率" | 平时用这个：跟得上你切窗口，又不浪费流量 |
| **自动** | **按设定间隔无条件一直推** | 想拿平板当实时副屏 |

### ⚠️ 两个频率，别搞混

右键菜单里有两项设置，含义完全不同：

| 菜单项 | 管哪个模式 | 含义 |
|---|---|---|
| **自动：推送间隔 N 秒** | 自动模式 | **定时器**——每隔 N 秒必定推一张，不管你切不切窗口 |
| **智能：最高刷新率 N 秒** | 智能模式 | **限速阀**——只在切应用时才推，且最快 N 秒刷一次；不切应用则一张都不推 |

两者下限不同：**自动最小 6 秒、智能最小 5 秒**
（一次截图 + 上传本身就要 2~3 秒，填更小只会让请求互相排队）。
填了不合规的数字会被挡下来并提示。

### 流量参考

| 模式 | 一小时 | 一天（一直挂着） |
|---|---|---|
| 手动 | 看你点几次 | — |
| 智能（5 秒） | 看你切几次窗口 | 几 MB ~ 几十 MB |
| 自动（6 秒） | ~600 张 ≈ 90MB | **2GB+** |

⚠️ 走的是学校服务器。**自动模式别长期挂着**，容易引人注意。平时用智能模式。

### 切换模式时

- 切到**自动** → 立刻推一张，之后按间隔一直推
- 切到**智能** → 不立刻推，等你换应用才推
- 切到**手动** → 只等你点

三种模式下，上一次还没传完时新的一次都会跳过（不排队堆积），
所以平板上永远是能拿到的最近一张，不会看到一串过期画面。

### 退出

右键悬浮窗 → 退出。程序不会自启，关掉就是彻底关掉。

## 平板那边

打开那本叫「电脑显示」的笔记，看到的图就是电脑屏幕。

**注意**：如果笔记一直开着不动，App 可能缓存旧图 —— 退出笔记再重新打开就能看到最新的。

---

## 图片规格

| 项目 | 值 |
|---|---|
| 抓取范围 | 主屏工作区（自动排除任务栏） |
| 笔记页宽度 | 固定 1920 |
| 笔记页高度 | **按屏幕比例自动算** |
| 图片尺寸 | 铺满整页，不留白 |
| 编码 | JPEG 质量 85，约 150 ~ 260 KB |

**页面高度跟着你屏幕的比例走**，所以图能占满整页：

| 屏幕比例 | 笔记页尺寸 | 图占页面 |
|---|---|---|
| 16:9 | 1920×1080 | 100% |
| 16:10 | 1920×1200 | 100% |
| 4:3 | 1920×1440 | 100% |
| 21:9 带鱼屏 | 1920×810 | 100% |

（早先版本页面固定 1920×2184，图只能占 49%，下面一半永远是白的。
 实测确认系统接受非标准页面尺寸后，改成了动态计算。）

因为图铺满整页，体积比"半页图"略大（约 150KB → 250KB）。换来的是**图大一倍**，值。

## 文件在哪

```
%LOCALAPPDATA%\ScreenPush\
├── account.json    账号密码（明文，注意别乱传这台电脑）
├── note.json       笔记身份（fileId 等，删了会新建一本笔记）
├── settings.json   两个模式的频率 + 日志开关
├── mode.txt        上次选的模式
├── last.txt        上次推送时间
├── push.log        上传日志（菜单里可以直接打开）
└── error.log       程序崩溃时的记录
```

---

## 已知限制

> ⚠️ **不适配竖屏显示器。**
> 程序是按**横向屏幕**设计的。屏幕高度大于宽度的情况（旋转过的显示器、竖屏摆放）
> **没有测试过，不保证效果**，请不要在竖屏下使用。
>
> ⚠️ **只抓主显示器的画面。** 接了多个显示器时，其余屏幕的内容不会出现在图里。
>
> ⚠️ **别把 exe 分享出去。** 里面虽然没有你的账号（凭据存在各人自己电脑上），
> 但包含完整的接口协议 —— 相当于把整套操作方法一起交出去了。

## 出问题了

两个地方看：

- **上传不成功 / 图没更新** → 右键菜单「打开日志文件」看 `push.log`，里面是最近一次推送的完整过程
- **程序打不开 / 闪退** → 看 `%LOCALAPPDATA%\ScreenPush\error.log`（exe 没窗口，崩溃信息只能落这儿）

常见情况：

- **弹"设置账号"但填了没反应** → 账号密码不对，或者网络不通
- **推送显示"失败：..."** → 大概率网络问题，等会儿再点
- **平板上图没变** → 把笔记退出重进；还是没变说明 App 缓存了，等一会儿或者换个页面再进来
- **双击没反应** → 可能已经在后台跑着了，看右下角有没有悬浮窗

## 自己构建

### 环境要求

- **Python 3.10 或更高**（用官方安装包，自带 tkinter；精简版可能没有）
- 装依赖：

```
pip install -r requirements.txt
```

### 跑源码（不用打包）

双击 `run_dev.bat`。它会自己找 Python（先试常见安装位置，再退回 PATH）。

带个黑窗口是故意的 —— 报错直接显示在里面。

命令行单次推送（调试最方便，会打印完整上传过程）：

```
run_dev.bat --cli
```

### 打包成单文件 exe

```
python build.py
```

⚠️ **要 2 分钟以上**，别以为卡死了。产物在 `dist\屏幕推送.exe` —— 单个文件，拷走就能用。

### 三个别踩的坑

1. `templates/` 里那 8 个文件**必须**跟着一起打包（`build.py` 已经处理好了）
2. 仓库里的 **`.gitattributes` 别删** —— 它把模板标记成二进制文件，
   防止 git 改动模板里的换行。改坏了的话，构建出来的程序打不开笔记
3. 打包请在**命令行**跑而不是双击 py 文件，那样能看到进度

### 测试三种模式时

- **自动模式**会真的按间隔一直推，测完记得切回手动
- **智能模式**切到别的窗口才会触发
- 想看真实效果，就在平板上打开那本笔记

## 原理备忘

云笔记的一页 = 8 个模板文件 + 1 张图。我们只换那张图。

关键是**钉死 fileId + page_hash**，把 OSS 路径固定下来：

- `fileId`（笔记身份）→ 覆盖同一本，不新建
- `page_hash`（路径中间那层时间戳）→ 路径不变，只换一张图
- ⚠️ **日期不能钉死**。临时凭证按天签发，只允许写**当天日期**的目录；
  跨天后必须换一个新的 `page_hash` 落到今天，否则直接 403 AccessDenied。
  （程序会自动处理，不用管）

⚠️ **不能钉死 `datetime.now()`** —— STS 签名带时间戳，钉死会报 `Expired data`。
